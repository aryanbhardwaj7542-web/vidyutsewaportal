# PowerLine Helper

Prompt:

Build a modern, responsive Electricity Complaint Management System website for an electricity department like Vidyut Bhawan, Patna. The project should have a clean, professional government-style design using HTML, CSS, JavaScript, Bootstrap, PHP (or Node.js/Python), and MySQL.

User Features:

User Registration and Login

Secure authentication

Dashboard after login

Register a new electricity complaint

Complaint categories:

Power Failure

Meter Issue

Billing Issue

Transformer Fault

Street Light Problem

Electric Pole Damage

Loose Wire

Other

Complaint form fields:

Consumer Number

Name

Mobile Number

Email

Address

District

Complaint Category

Complaint Description

Upload Image (optional)

Generate a unique Complaint ID automatically.

View complaint history.

Track complaint status (Pending, In Progress, Resolved).

Edit profile.

Admin Features:

Secure Admin Login

Dashboard showing:

Total Complaints

Pending Complaints

In Progress Complaints

Resolved Complaints

Today's Complaints

View all complaints in a searchable table.

Filter complaints by district, category, status, and date.

Update complaint status.

Assign complaints to technicians.

Add remarks while resolving complaints.

Delete duplicate complaints.

Export complaint reports as PDF and Excel.

Additional Features:

Email notification when a complaint is registered.

Success message after submission.

Search complaints using Complaint ID.

Forgot Password functionality.

Contact Us page.

About Department page.

FAQ page.

Emergency contact numbers.

Dark Mode and Light Mode toggle.

Responsive design for desktop, tablet, and mobile.

Form validation on both client and server sides.

UI Requirements:

Professional government-style interface.

Blue and white color theme with subtle gradients.

Navbar with logo, Home, About, Complaint, Track Complaint, Contact, Login.

Hero section with a banner related to electricity services.

Cards displaying department services.

Statistics section with animated counters.

Footer containing address, emergency contacts, social media links, and copyright.

Smooth scrolling and modern animations.

Database:

Create MySQL tables for:

Users

Admins

Complaints

Complaint Status History

Technicians

Include SQL scripts to create the database.

Project Structure:

Organize the project into separate folders for HTML/PHP pages, CSS, JavaScript, images, uploads, and database files. Follow good coding practices with comments and clean code.

Bonus Features:

Display complaint locations on Google Maps.

Dashboard charts using Chart.js.

SMS notification integration (placeholder).

Role-based login (User, Technician, Admin).

Automatic complaint number generation.

Loading animations and toast notifications.

Accessible and responsive design.

Deliver a complete, production-ready project with clean code, proper folder structure, database integration, and setup instructions.
